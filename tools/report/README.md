# Еженедельный отчёт о поведении покупателей (MarMar)

Запускается по расписанию в сессии «САЙТ МАГАЗИН» (Claude):

- **пн, ср, пт ~10:23 по Риге** — `python3 tools/report/clarity_snapshot.py` → `analytics/clarity/ГГГГ-ММ-ДД.json`
  (API Clarity хранит только 3 дня и даёт 10 запросов в сутки; один снимок = 3 запроса).
- **по понедельникам** дополнительно:
  - `python3 tools/report/ga4_week.py` — воронка, каналы, устройства, входы, товары, выходы (7 дней + прошлая неделя);
  - `node tools/report/wc_week.js` — заказы по источникам и проданные товары (точнее, чем GA4);
  - снимки Clarity за неделю — «пустые» и «злые» клики, быстрые возвраты, ошибки скриптов, боты;
  - Claude пишет Алине короткий отчёт на русском: цифры недели, что изменилось, 2–3 совета.

Доступы: GA4 — `GOOGLE_SERVICE_ACCOUNT_JSON`; WooCommerce — `WP_ADMIN_USER`/`WP_ADMIN_PASSWORD` (вход через Playwright);
Clarity — ключ подставляет прокси окружения для `www.clarity.ms` (в коде и переменных его нет).
Сайт почти не нагружается: один вход в админку в неделю.
