# Карта редиректов со старого сайта (Mozello) — ноябрь 2026

Подготовлено 31.10.2026. На сайте пока **ничего не изменено**: внедряет Алина по инструкции ниже.

## Что это и зачем

Google до сих пор знает **1 015 адресов** сайта (Search Console, июнь 2025 – октябрь 2026). Проверил каждый:

| Состояние сейчас | Адресов |
|---|---|
| ✅ открывается сразу или с одним нормальным редиректом | 361 (не трогаем) |
| ❌ редирект ведёт на **404** (страница не найдена) | 519 |
| ⚠️ цепочка из 2–3 редиректов | 70 |
| ⚠️ редирект через технический домен `marmarcandles.area.lv` | 32 |

Новая карта: **621 редирект**, каждый — **один 301** сразу на живую страницу (все 144 целевые страницы проверены: отвечают 200 без редиректов). Ни один редирект не перехватывает существующую страницу.

Что даст: покупатели по старым ссылкам (закладки, Pinterest, Instagram, Google) попадают к товару, а не на 404; Google передаёт «вес» старых страниц новым; убираем путаницу с `area.lv`.

## Как подбиралась цель

1. Цепочка уже вела на правильную живую страницу → один прямой редирект туда же.
2. Старый товар → тот же товар на новом сайте (по адресу и названию; цифры, размеры и цвет обязаны совпадать — «cipars 2» никогда не уйдёт на «cipars 3»).
3. Товара больше нет → его категория (например, все старые молды → категория `svecu-veidnes`).
4. Старые латышские статьи → та же статья на новом сайте; английские статьи → ближайшая латышская тема.
5. Старые служебные страницы (kontakti, piegāde, BUJ, noteikumi…) → их новые версии.

Не включены: картинки Mozello (`/files/…`), корзина/аккаунт Mozello, главная `www.` (это отдельная задача про canonical и `/lv/`).

## Как внедрить (вариант A, бесплатно, ~20 минут)

1. **Резервная копия.** Rank Math → General Settings → Edit .htaccess (если раздела нет — включить «Advanced mode» в панели Rank Math). Скопировать **всё** содержимое в текстовый файл на компьютер.
2. Вставить содержимое `htaccess-redirects-2026-11.txt` **в самый верх**, выше строки `# BEGIN WordPress`. Сохранить.
3. Сразу открыть в браузере: главную, любую категорию, любой товар, корзину. Если сайт не открывается (ошибка 500) — вернуть копию из шага 1, написать мне.
4. Проверить 2–3 старых адреса, например:
   - `https://www.marmarcandles.com/veikals/category/svecites-tortem-un-kukam/` → должен сразу открыть «Tortes sveces»;
   - `https://www.marmarcandles.com/home-2/` → главная.
5. Написать мне «готово» — я запускаю автоматическую проверку всех 621 адресов:
   `python3 tools/redirects/check_redirects.py seo/redirects/rankmath-redirects-2026-11.csv --www`
6. **После успешной проверки** — убрать старые записи в Rank Math → Redirections, которые ведут на `marmarcandles.area.lv` (они больше не срабатывают, но мешают порядку). Скажу точный список.

Вариант B (если есть Rank Math PRO): Rank Math → Redirections → Import & Export → импорт `rankmath-redirects-2026-11.csv`. Все записи попадут в категорию `mozello-2026-11`, их легко найти и при необходимости удалить разом.

## Попутно найдено: http:// не работает

Адреса с `http://` (без «s») отвечают ошибкой **503**, а должны перенаправлять на `https://`. Обычно это включается в панели хостинга area.lv («Force HTTPS» / «Piespiedu HTTPS») или вопросом в поддержку. Старые ссылки и часть Google-адресов на `http://` сейчас не открываются вовсе.

## Как обновить карту в будущем

Скрипты в `tools/redirects/` (нужен ключ Google в `GOOGLE_SERVICE_ACCOUNT_JSON`), запускать из рабочей папки с подпапкой `redir/`:
`gsc_urls.py` (адреса из GSC) → `trace.py` (текущие цепочки) → `targets.py` (живые страницы) → `build_map.py` (подбор цели; ручные исправления — словарь `OVERRIDES`) → `validate.py` (цели отвечают 200) → `export.py` (файлы в эту папку).
