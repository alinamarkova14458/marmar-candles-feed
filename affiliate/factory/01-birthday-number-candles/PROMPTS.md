# Набор 1 — Watercolor Birthday Number Candles

**Что продаём:** ~22 PNG-элемента в одном стиле — свечи-цифры 0–9, торты, капкейки и праздничные мелочи.
Покупатель собирает из них свой торт с нужным возрастом (открытки, приглашения, наклейки, топперы).
**Палитра:** пудрово-розовый, персиковый, шалфейный, сливочный + чуть золота. Акварель, мягко, «дорого».

---

## Как генерировать в ChatGPT (важно — сэкономит время)

1. **Всё в ОДНОМ чате.** Тогда ChatGPT помнит стиль, и серия выходит одинаковой.
2. Первым сообщением отправь блок **«СТИЛЬ»** (ниже) целиком. Дальше — короткие запросы из списка.
3. **Одна картинка = один предмет.** Не проси несколько предметов на одной картинке.
4. Если картинка не понравилась — напиши «ещё раз, тот же стиль» (не начинай новый чат).
5. **Скачивай оригинал** (кнопка скачивания на картинке), а не скриншот.
6. Кидай файлы в Google Drive: `jalina-factory / 01-inbox / 01-birthday-number-candles`.
   Имена файлов можно не менять — переименую сама.
7. Брак не страшен: я сама отберу лучшие. Лучше прислать 2 варианта, чем один кривой.

## СТИЛЬ (отправить первым сообщением, один раз)

```
I'm making a cohesive watercolor clipart set for birthday cards. Use this exact style for every image in this chat:
- soft hand-painted watercolor with visible paper texture and gentle color bleeding
- delicate thin ink outlines, slightly imperfect, hand-drawn feel
- palette: blush pink, peach, sage green, warm cream, small touches of muted gold; no neon, no harsh black
- one single object per image, centered, fully visible with margin around it
- transparent background (PNG); if transparency is not possible, pure flat white background
- no text, no watermark, no shadow on the ground, no frame
- square image, highest resolution available
Reply "ready" and wait for my requests.
```
